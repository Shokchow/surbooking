Surbooking · mise à jour le 8 novembre 2026

Surbooking est un jeu créé par Raphaël Dubois (France). Il ne vous demande ni compte, ni nom, ni adresse e-mail. Cette page dit ce que la version en ligne du jeu (page web, page itch.io, version Windows) garde, pourquoi et combien de temps.

Ce que le serveur du jeu garde

Le jeu ne contacte pas son serveur tant que vous n'avez pas ouvert un mode en ligne (Session du jour, En direct), choisi un pseudo, accepté les résumés de partie ou partagé un duel. Avant cela, tout reste sur votre appareil.

Ce qui n'est jamais collecté

Pas de nom réel, pas d'adresse e-mail, pas de compte, pas de position, pas de contacts. Pas de publicité, pas de traceur, pas de mesure d'audience. Les polices, les images et les voix sont livrées avec le jeu : aucun service tiers n'est appelé pendant la partie, à part le serveur du jeu.

Où sont les données

Le serveur du jeu est hébergé par Supabase, en Europe (Paris). La page web est hébergée par GitHub Pages et la version Windows par itch.io : comme tout site, ces hébergeurs voient votre adresse IP quand vous ouvrez la page ou téléchargez le jeu (voir leurs propres politiques). Le serveur du jeu voit aussi votre adresse IP le temps de répondre ; le jeu ne la garde pas.

Sur votre appareil

Votre progression, vos réglages, votre partie en cours et la clé de joueur restent dans le stockage de votre navigateur ou de l'application. Effacer les données du site ou désinstaller le jeu les supprime, et fait de vous un nouveau joueur.

Pourquoi c'est permis

Les données en ligne servent à faire fonctionner les fonctions en ligne que vous utilisez (intérêt légitime). Les résumés de partie reposent sur votre accord : vous pouvez le retirer à tout moment dans le jeu.

Vos droits

Vous pouvez accéder à vos données, les corriger, les effacer ou vous opposer à leur usage. Le plus simple : dans le jeu, Règles → Entre amis → Effacer mes données en ligne retire du serveur vos decks, résultats du jour, résumés de partie et pseudo. Pour un duel partagé ou toute autre demande, écrivez au créateur depuis la page itch.io du jeu ou le dépôt GitHub. Vous pouvez aussi saisir la CNIL.
