Privacy

Surbooking · updated November 2, 2026

Surbooking is a game made by Raphaël Dubois (France). It never asks for an account, a name or an e-mail address. This page explains what the online version of the game (web page, itch.io page, Windows version) keeps, why, and for how long.

What is never collected

No real name, no e-mail address, no account, no location, no contacts. No ads, no trackers, no analytics. Fonts, images and voices ship with the game: no third-party service is called while you play, apart from the game server.

Where the data lives

The game server is hosted by Supabase, in Europe (Paris). The web page is hosted by GitHub Pages and the Windows version by itch.io: like any website, these hosts see your IP address when you open the page or download the game (see their own policies). The game server also sees your IP address while it answers; the game does not keep it.

On your device

Your progress, settings, current run and player key stay in your browser's or the app's storage. Clearing the site's data or uninstalling the game deletes them, and makes you a new player.

Legal basis

Online data is used to run the online features you use (legitimate interest). Game summaries rely on your consent, which you can withdraw at any time in the game.

Your rights

You can access, correct or erase your data, or object to its use. The simplest way: in the game, Rules → With friends → Erase my online data removes your decks, daily results, game summaries and nickname from the server. For a shared duel or any other request, write to the creator from the game's itch.io page or the GitHub repository. You can also contact the French data protection authority, the CNIL.
